注册页 · 美化方案

先说个重要发现：注册页此前看起来「没设计过」，是因为漏了一行 @import。

登录页的 Login.css 第 6 行有 @import './Auth.css'，注册页没有 —— 于是 .auth-page / .auth-card / 品牌区 / 表单控件样式全部失效，页面渲染成一串贴着屏幕边缘的裸控件。这一行我已经补上，下面是补齐之后的效果，以及在此基础上的两个美化方向。

1先看修复 @import 的效果

左边是补 @import 之前，右边是之后。这一步不是美化，是把已有的设计找回来。

2修复之后仍然不够精致的四处

1
必填星号是浏览器默认样式的裸 *，颜色还是正文色（rgb(74,64,51)），既不是红也不够显眼 —— 看起来像标签的一部分而不是必填标记。
2
品牌区只有两行居中的文字（「友声」+「嘤其鸣矣」），没有任何视觉锚点。整页第一眼落不到任何东西上。
3
表单是一路的平铺：5 个字段等距排下去，中间那条「以下可跳过」的细分隔几乎看不见 —— 用户分不清哪些必填、哪些可跳。
4
按钮禁用态是淡青（rgb(135,186,200)），像一块半透明的色块浮在米底上，不像「还没准备好」的按钮。

3方案 A · 精致克制（推荐）

保留单卡片结构，只打磨细节：印鉴徽标、必填圆点、分段标签、实底按钮。

元素改前改后
品牌区两行居中文字加一枚 46px 圆角印鉴（「友」字 + 青色渐变），给整页一个视觉落点

跳过分隔细线 + 裸文字胶囊标签「以下可跳过 · 之后也能认证」，用浅米底把它做成一个可识别的区块边界
主按钮禁用态淡青 #87bac8禁用态用 #cfe3e9（更淡、更干净）；可用态加 柔和投影，让它有按下感
为什么用「印鉴」而不是普通 logo。 产品名「友声」出自《诗经》「嘤其鸣矣，求其友声」，本身就是文人气的调子。 一枚印章形状的青色徽标比抽象的圆点更贴这个气质，也比画一个图标更省事 —— 里面就一个「友」字，用系统字体渲染，不需要任何图片资源。

4方案 B · 分组卡片

把表单拆成两张卡：账号（必填）与校内身份（选填），让「可跳过」这件事在结构上就成立，而不是靠一条分隔线解释。

两方案的区别
A · 精致克制B · 分组卡片
结构一条表单流到底两张卡：账号 / 校内身份
「可跳过」怎么表达一条胶囊标签划边界第二张卡自带「可选」角标
视觉密度轻，留白多，像 iOS 设置页更结构化，像一张表单卡
首屏能否放下更紧凑（分隔条比卡片省 ~40px）卡片内边距让页面更长，需滚动
改动量只改 CSS + 微调模板模板要重新分组，改动更大
我推荐 A。理由有三： ① 注册页的首要目标是让人赶紧填完，卡片分组会额外增加视觉重量与页面长度； ② B 的「两张卡」在 390px 下每张都要内边距 + 边框，5 个字段会被推出一屏，反而更累； ③ A 只改样式，不动表单结构，回归风险最低 —— 而这块刚改过必填规则，不适合再动骨架。
