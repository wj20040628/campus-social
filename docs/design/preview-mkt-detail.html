标题与分类完全重复：实测 DUP_TITLE: true —— 徽章写「跑腿代办」，下面 22px 大字也写「跑腿代办」。根因和后端 derivedTitle() 有关：用户没填标题时它拿分类兜底，于是 mainText === category。集市列表卡片已修（标题与分类相同时不渲染），详情页同样要修。
2
两层「活动详情」横条叠在一起：最上面是全站顶栏（y=0 高 56），下面又有一层自绘返回条 .md__bar（y=89 高 57）。两条都写着「活动详情」、都有返回箭头 —— 用户会疑惑该点哪个。自绘那条应当去掉，返回交给全站顶栏。
3
信息卡 2×2 占 156px：实测手机端 infoRows: 2，四张 ~150px 宽的白卡排成两行，每张卡里只有一个图标 + 两行文字。这四块内容是「地点/价格/人数/剩余」，本质是一组**同质键值对**，用 2×2 大卡承托过于隆重，也把首屏竖向空间吃掉一大块。
4
保留：免责声明用暖米底块而非彩色边框、留言区警示用橙色描边、{{ }} 插值禁用 v-html —— 这三处的安全与克制是对的，不动。
