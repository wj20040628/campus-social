## 2. 断点写法（三处同步纪律的第 3 处）

`SPEC.md §10.4` 裁定：断点唯一源是 `design-tokens.json`，三处同步靠文档纪律。**当前 `design-tokens.css` 还没有 `@custom-media` 段**，Phase 3 前端须先在 `frontend/src/styles/design-tokens.css` 末尾补上这一段，再在各 SFC 里用 `@media (--ys-bp-lg)`：

```css
/* design-tokens.css 末尾追加。值必须逐字对齐 design-tokens.json 的 breakpoint 段 */
@custom-media --ys-bp-sm  (min-width: 640px);
@custom-media --ys-bp-md  (min-width: 768px);
@custom-media --ys-bp-lg  (min-width: 1024px);
@custom-media --ys-bp-xl  (min-width: 1280px);
@custom-media --ys-bp-2xl (min-width: 1536px);
```

若构建链（postcss-preset-env）不可用 `@custom-media`，退化为直接写 `@media (min-width: 1024px)`，**但值必须仍是这 5 个**。

**禁止**使用 Element Plus 的 `el-col` 响应式属性（`:xs` `:sm` `:md` `:lg` `:xl`）——EP 2.14.5 内置 768/992/1200/1920，与本项目断点错位（`SPEC.md §10.3` 第 3 条）。栅格一律 CSS Grid。

**全局 tablet 留白缺口（advisory）**：`design-tokens.json` 有 `gutterTablet: 24px`，但 `design-tokens.css` 只导出了 `--ys-gutter-phone` / `--ys-gutter-desktop`，没有 `--ys-gutter-tablet`。本目录统一口径：**≥768px 一律用 `--ys-gutter-desktop`（24px）**，不新增 Token。Phase 3 不要自己发明第三个 gutter 变量。

## 3. 安全区与视口高度公式（每页通用）

```css
/* 内容区底部留白：TabBar 高度 + iPhone 底部安全区 */
.ys-page-pad-bottom {
  padding-bottom: calc(var(--ys-tabbar-h) + var(--ys-safe-bottom));
}

/* 移动端视口高度：100vh 会被地址栏遮挡，一律用 dvh，vh 仅作降级 */
.ys-full-height {
  height: 100vh;      /* 降级：不支持 dvh 的老浏览器 */
  height: 100dvh;
}
```

- `--ys-safe-bottom` = `env(safe-area-inset-bottom, 0px)`，已在 Token 中定义。
- 顶部/左侧/右侧安全区 Token 里没有，需要时**直接写** `env(safe-area-inset-top, 0px)`——它是尺寸不是颜色，不违反「零硬编码颜色」。
- `index.html` 的 viewport 必须补 `viewport-fit=cover`，否则 `env()` 恒为 0：
  ```html
  <meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover" />
  ```

## 4. 五态覆盖模板（每个列表/每个异步区块都必须有）

| 态 | 强制要求 | 违例判定 |
|---|---|---|
| **空态** | 一句人话主句（`--ys-text-2xl` / 600）+ 一句副句（`--ys-text-sm` / `--ys-muted`）+ **一个可点击行动按钮** | 出现「暂无数据」「敬请期待」「No Data」即失败（`SPEC.md §9 AC-19`） |
| **加载骨架屏** | 骨架条目数 3–6 条，形状对齐真实条目的行数与头像位，微光用 `--ys-ease-linear`；**首屏不用全屏 spinner** | 骨架形状与真实条目不一致会造成 CLS |
| **错误** | 具体原因 + 「重试」按钮。文案说人话：「网络好像断了，点这里重试」，禁止「操作异常，请重试」 | 只弹一个无按钮的 toast = 不合格 |
| **权限不足** | 明确说清「为什么看不了」+ 一个退路按钮（返回上一页 / 去首页）。管理员页 403 与游客态都要覆盖 | 白屏或直接跳首页无提示 = 不合格 |
| **内容超长** | 标题 1–2 行截断、昵称 1 行截断、正文单行 URL/无空格长串 `overflow-wrap: anywhere`、计数 999+ 封顶 | 出现横向滚动即失败（`AC-15`） |

## 5. 动效与无障碍硬约束（每页通用，不逐页重复论证）

- 时长只允许 5 档：`--ys-motion-instant`(80ms) / `--ys-motion-fast`(150ms) / `--ys-motion-base`(200ms) / `--ys-motion-slow`(280ms) / `--ys-motion-page`(320ms)。**320ms 是硬上限。**
- 缓动只允许 3 条：`--ys-ease-out` / `--ys-ease-in-out` / `--ys-ease-linear`。**禁止任何 y<0 或 y>1 的控制点**（禁止 overshoot / 弹跳）。
- 只动 `transform` 与 `opacity`，禁止动 `width` / `height` / `top` / `left`。
- 触控热区 ≥ 44×44px（`--ys-touch-min`），相邻可点元素间距 ≥ 8px（`--ys-space-2`）。
- 焦点样式只能是 `:focus-visible { box-shadow: var(--ys-focus-ring) }`。**禁止 `outline: none` 而不给替代。**
- 纯图标按钮必须有 `aria-label`；列表用 `ul/li`；导航用 `nav`；可点元素用 `button` 不用 `div @click`。
- 语义色（成功/警告/错误）必须「图标 + 文字 + 颜色」三重传达，禁止只靠颜色。

## 6. Token 引用纪律

- 业务代码里出现的每一个颜色都必须是 `var(--ys-*)`，唯一例外 `#fff` / `#000`。
- 阴影色相一律 `rgba(16, 33, 46, *)`，禁止 `rgba(0, 0, 0, *)`。
- 每个页面文件末尾的「Token 引用清单」是**穷举**——清单外的 `--ys-*` 不应出现在该页。清单内没写的 Token 若被用到，视为新增需求，需回设计师确认。
- 现有代码里的硬编码残留（Phase 3 必须清）：
  - `frontend/src/views/Chat.vue:1027` `#b3f0c8` —— 已读气泡文字色，属硬编码。
