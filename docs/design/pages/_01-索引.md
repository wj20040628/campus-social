## 2. 16 个页面一览

| 文件 | 路由 | 档位 | 移动端核心形态 | 最关键的一条判断 |
|---|---|---|---|---|
| `MainLayout.vue.md` | 全站 | 重 | 顶栏 56px + 底部 TabBar 56px + 内容区 | 顶栏**保留** 56px 但重构内容；中间的圆形「+」在移动端删除（TabBar 已有发布位） |
| `Chat.vue.md` | `/chat` | 重 | 列表页 / 会话页**单栏路由切换** | 会话页**隐藏 TabBar**，否则与输入法区抢底部空间 |
| `CircleDetail.vue.md` | `/circles/:id` | 重 | 圈子头 + 内嵌发帖 + 双 Tab | 480px 弹窗改**全屏抽屉**，`label-position="top"` |
| `AdminReview.vue.md` | `/admin/review` | 中 | **逐条处置队列** + 吸底操作栏 | 手机上一手握持：主操作吸底、不进二级菜单、处置后 5 秒可撤销 |
| `AdminAudit.vue.md` | `/admin/audit` | 中 | 筛选条吸顶 + 日志单列流 | 日志是**只读**的，移动端砍掉「用户下拉全量拉取」 |
| `Home.vue.md` | `/` | 中 | 公告条 + 兴趣入口 + Feed 单列 | 第一屏**不许有 Hero**，落地就是内容 |
| `PostDetail.vue.md` | `/post/:id` | 中 | 正文流 + 吸底评论输入 | 评论输入吸底，与 TabBar 互斥（详情页隐藏 TabBar） |
| `Publish.vue.md` | `/publish` | 中 | 全屏编辑器 + 吸底发布栏 | 字数与图片预览在**同一屏**内可见 |
| `Profile.vue.md` | `/user/:id` | 中 | 头像头 + 三统计 + 三 Tab | 封面横幅在移动端**去掉**，头像直接顶到内容上沿 |
| `Circles.vue.md` | `/circles` | 中 | 单列圈子行（不是卡片网格） | 桌面可网格，手机必须单列全宽行 |
| `Login.vue.md` | `/login/form` | 中 | 单列表单，卡片撑满留白 | **删掉渐变背景**，改纯 `--ys-bg` |
| `Register.vue.md` | `/login/register` | 中 | 单列表单 | 同 Login；5 个字段压到 4 屏内不可见，改单屏滚动 |
| `Announcement.vue.md` | `/announcement` | 新增 | 置顶分组 + 分类 chip 筛选 + 已读区分 | 置顶靠**分组 + 图钉**，不靠彩色左边框 |
| `AnnouncementDetail.vue.md` | `/announcement/:id` | 新新增 | 正文 + 吸底「我已了解」 | 已读回执**幂等**，重复点不报错、不重复写行 |
| `AdminAnnouncement.vue.md` | `/admin/announcement` | 新增 | 列表 + 全屏抽屉编辑器 | 手机端可用（OD-19）；「谁还没看」名单在手机上是折叠面板 |
| `Onboarding.vue.md` | `/onboarding` | 新增 | 3 步单列，进度条吸顶 | **第 1 步不可跳过**（AC-18），跳过按钮只出现在第 2、3 步 |

## 3. 跨页一致性检查清单（QA / 前端自测用）

- [ ] 375px 视口下 16 页全部无横向滚动（`AC-15`）
- [ ] 所有可点元素热区 ≥ 44×44px（`AC-15`）
- [ ] 任意列表为空时都有「一句人话 + 一个可点按钮」（`AC-19`）
- [ ] `rg -n "7C3AED|A855F7|9333EA|EC4899" frontend/src/ docs/` 零命中（§8.1 红线 3）
- [ ] `rg -n "cubic-bezier" frontend/src/` 命中项的控制点 y 值均在 [0,1]
- [ ] 全站无 emoji 字符充当图标（`Chat.vue:144/150`）
- [ ] 无 `:fullscreen` 之外的固定宽弹窗（380/480/420px 三处已改）
- [ ] 找搭子相关列表单元以「具体邀约」为主信息行，头像 ≤36px、昵称 13px（§8.1 红线 1）
