## 3. 1.13.4 交付了什么

主题：**举报处置「禁言」闭环 + 管理端可操作性**（用户拍板「补代码而不是改评估报告」）。

| # | 能力               | 关键实现                                                                                        |
| - | ---------------- | ------------------------------------------------------------------------------------------- |
| 1 | 用户处置页直连禁言        | `POST /admin/users/{id}/mute`，1/3/7/30 天，理由必填；`AdminUserServiceImpl.mute` 拒绝管理员、已封禁、已注销账号   |
| 2 | 举报处置新增 `mute` 动作 | 内容举报连带下架；审计 `report_mute`；通知 type 24                                                        |
| 3 | 已处置举报显示具体动作与时长   | `report.handle_action` + `handle_days`，前端 `utils/reportVerdict.js` 渲染「已禁言 7 天」等；历史行为空时回退旧文案 |
| 4 | 惩罚性处置必须写理由       | `requireNote()` 在 404/422 契约之后执行，保持错误码优先级；理由经通知展示给被处置人                                      |
| 5 | 本人可见禁言状态         | `/user/me` 下发 `muteUntil`；`MuteBanner.vue` 显示截止时间、受限动作与申诉入口（复用 `FeedbackDialog`）            |
| 6 | 「禁言中」筛选          | `GET /admin/users?muted=true` → `mute_until > NOW()`，与 `status` 正交                          |
| 7 | 解除禁言             | `POST /admin/users/{id}/unmute`；已封禁或未禁言时返回 422                                              |

**禁言边界（与封禁的区别）**

- 封禁：`user.status=1`，无法登录；管理员手动 1/7/30 天或永久；Redis 到期任务 + `BanExpireJob` 自动解封。
- 禁言：`user.mute_until` 到点自动失效，账号状态仍为 0，**可以登录和浏览**；只拦 **发帖（含编辑）/ 评论 / 私信 / 群消息** 四项；集市发布与文件上传不拦；重复禁言只延长不缩短。

## 3.1 1.13.5：账号自助注销（个人信息删除权）

**发现的缺口**：隐私政策与用户协议都写着「有权申请注销账号」，但代码里 `user.status=2`（注销）**从未被任何路径写入**——既没有用户入口，也没有管理端入口。承诺与实现不符。

**本次实现**

| 项 | 内容 |
| --- | --- |
| 发码 | `POST /user/cancel/code`：向本人绑定邮箱发 `type=cancel` 验证码，返回打码邮箱；拒绝已注销、管理员、未绑邮箱 |
| 注销 | `POST /user/cancel`：验证码确认后 `status=2`；`username` 改为 `deleted_{id}`；`email`/`student_no` 置 NULL（释放唯一键，日后可用同一邮箱重新注册）；昵称改「已注销用户」；简介/头像/封面/院系年级专业/校区清空；认证状态归零、密码哈希置未设置；`mute_until` 清空 |
| 会话 | 吊销全部 refresh 令牌 + 删除 `user:status:{id}` 缓存，旧 token 立即失效 |
| 留痕 | 审计 `account_cancel`；已发布帖子/评论保留并显示「已注销用户」（不删行，避免举报/审计记录变孤儿） |
| 前端 | 设置页新增危险项「注销账号」，弹窗两步：发码 → 输码 + 勾选确认；成功后清本地会话回登录页 |
| 隐私政策 | 重写：更正「邮箱选填」为**注册必填**；补 OSS 私有存储、邮件推送两项实际第三方；补保存期限（日志/处置记录 ≥6 个月）；补查看/更正/删除/注销/投诉的具体操作路径；说明当前未启用第三方大模型审核 |
| 日志脱敏 | 登录失败审计、注册审计、绑邮箱审计、发码与复用日志统一改为 `maskUsername` 打码，`audit_log` 不再落完整邮箱/学号 |

**验证**：新增 `AccountCancelFlowTest` 7 条（清空字段、令牌与缓存失效、错码不改状态、重复注销拒绝、管理员拒绝、旧密码无法登录、邮箱可重新注册）；发布时后端全量 **201/201**、前端 **11 门禁**、生产构建通过；OpenAPI 补两条路径与 `CancelAccountRequest`，契约门禁 0 悬空引用。工作树又补 4 条注销回归用例，当前全量 **214/214**。

**状态**：已随 1.13.5 于 2026-11-01T10:22:50+08:00 上线；公网可区分 `/api/user/cancel`（401）与不存在路径（404），线上 `Settings` chunk 含「注销账号」。

## 8. 产品与规则口径（当前实现）

- **游客态**：只展示公开浏览入口；消息、我的、通知、公告、文件等登录项**不渲染**；误入登录态页面弹「先逛逛 / 去登录」。桌面游客首页为动态流 + 右栏推荐圈子/集市/话题 + 侧栏登录卡。
- **发帖准入**：注册即可发帖/评论/点赞/加入圈子；陌生人搭话、建圈、建群/邀请、圈子活动报名、集市发布要求注册满 24 小时且信誉分 ≥60。
- **发帖配额**：按信誉分档位每日 5/10/15 条；集市在投配额 1。
- **注册与密码**：邮箱验证码登录即注册，昵称自动生成「用户+6 位随机数」，不强制设置密码；新账号首次进首页有约 4 秒的设置密码提示，可点击直达账号与安全。
- **注销账号**：验证码确认后停用、匿名化并释放邮箱/学号唯一键；已注销账号不可登录、不可被封禁、不可被 @、不可被关注或私信。
- **举报处置动作**：`ban` / `mute` / `takedown` / `reject` / `ignore`，乐观 `UPDATE ... WHERE status=0` 防并发重复处置；成立扣信誉 20。
- **通知类型**：24 禁言、25 解除禁言、18 举报回执、19 封禁、20 内容下架、21 解封、23 圈子解散。
